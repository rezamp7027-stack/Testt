Why Testt exists.

Testt is a fictional premium storefront created as a clean foundation for a real e-commerce project. The visual system is deliberately restrained: strong typography, generous spacing, subtle borders, and focused product presentation.

The site is static and GitHub Pages friendly. Products, cart behavior, and navigation work without a server; a real backend and payment provider can be connected later.
